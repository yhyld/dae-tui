# dae-tui 快速开始

本指南面向第一次使用 dae-tui 的用户：从安装、登录到完成「测速 → 固定节点 → 切路由预设 → 重载生效」的完整闭环。各页面键位的完整清单随时可在 TUI 里按 `?` 查看，本文只讲高频路径。

## 它是什么

dae-tui 是 [dae](https://github.com/daeuniverse/dae) eBPF 代理的终端管理界面。它通过 [daed](https://github.com/daeuniverse/daed) 的 GraphQL API 工作，可以：

- 查看代理状态、实时流量、各组当前节点
- 测速并按延迟筛选节点，把某个节点固定给某个组
- 管理订阅与手动节点（批量导入、原地编辑）
- 切换并编辑 config / DNS / routing 方案，或用内置路由预设一键切换
- 在命令行以非交互方式查询状态、触发测速（可绑快捷键、写脚本）

## 前置要求

- 一个正在运行的 **daed**（v2.1.1，GraphQL API 可访问）
- 支持 UTF-8 和 ANSI 颜色的终端，窗口至少 **60 列 × 12 行**
- 从源码构建需要 Go 1.27.1+

## 安装

从 GitHub Releases 下载对应平台的二进制，或从源码构建：

```bash
git clone https://github.com/yhyld/dae-tui.git
cd dae-tui
go build -o dae-tui ./cmd/dae-tui
./dae-tui -version
```

## 准备后端

### daed 跑在本机

默认端点开箱即用：

```text
http://127.0.0.1:2023/graphql
```

### daed 跑在远程机器（SSH 隧道）

daed 的 API 是纯 HTTP，不要让它裸奔在公网上。远程部署建议让 daed 只监听回环（`daed run -l 127.0.0.1:2023 ...`），再用 SSH 隧道转发：

```bash
ssh -N -L 2023:127.0.0.1:2023 user@server
# 之后在本机运行 dae-tui，默认端点直接可用
```

dae-tui 的剪贴板复制（`y` 键）走 OSC 52，在 SSH 会话里同样可用。

### 关于流量统计

官方 daed v2.1.1 钉的旧版 wing 存在**上下行流量统计失真**的问题——首页速率/图表/累计会不对。这是后端版本问题，不是 dae-tui 的 bug。登录后按 `P` →「关于」里的**链路自检**可以判断你的后端是否受影响（黄字提示 = 旧链）。修复方法见 [daed-bare-metal-install.md](daed-bare-metal-install.md)（重钉 wing 子模块并重建 daed）。

## 首次启动

```bash
./dae-tui
# 或显式指定端点
./dae-tui -endpoint http://127.0.0.1:2024/graphql
```

- daed 还没有账户 → 进入**初始化表单**，创建管理员；
- 已有账户 → 显示**登录表单**。

登录成功后，用户名、密码和 JWT 会保存到 `~/.config/dae-tui/config.toml`（权限 `0600`，含凭据，不要外传）。JWT 有效期 30 天，过期后程序用保存的凭据自动续期，无需重复登录。想彻底退出登录：`P` → 账户 → 退出登录。

连接是否正常可以先用非交互自检确认：

```bash
./dae-tui -probe   # 只读打印：端点可达性、版本、组、订阅、网卡、方案
```

## 五分钟上手

先建立一个心智模型：**大多数修改（切方案、改订阅、动群组）不会立刻生效**——顶栏会出现黄字 `⚠ 需重载 (A) · N 项`，按 `A` 在确认框里查看待生效清单并重载，代理才切换到新配置。也可以在设置里开启「自动重载」，让 dae-tui 自己的改动延迟 2 秒后自动重载。

### 1. 看状态（首页，数字键 `1`）

首页是总览：代理运行状态、实时速率与流量图、当前选中的 config/DNS/routing 方案、各组当前节点、订阅摘要与网卡信息。组名前的绿点 `●` 表示该组正被当前路由方案引用（流量正在走的组）。

### 2. 测速（群组页，数字键 `2`）

按 `2` 进群组页，左栏 `j/k` 选中组，`Tab` 进右栏展开节点分区，然后：

| 按键 | 作用 |
| --- | --- |
| `T` | 只测当前选中的节点 |
| `t` | 测整组（或当前分区） |
| `/` | 打开过滤框，按 名称/协议/标签/地址 实时过滤 |
| `o` | 循环排序：默认 → 延迟升序 → 延迟降序 |

延迟列带微型色条：绿 <200ms、黄 <500ms、红更慢、灰未测。测速结束会响一声铃（桌面通知 + 终端铃声，音量在终端侧设置）。

### 3. 固定节点（把某组钉在某节点上）

在群组页把光标移到想要的节点上，按 `f`。dae-tui 会创建一个专用固定组（默认名 `pinned`）承担 `fixed` 策略，并把路由里对该组的引用改指固定组——**来源组的成员和订阅原样保留**，确认框会列出所有将改写的引用处，`y` 确认后按 `A` 重载生效。

解除固定回首页按 `x`（路由引用改回原组，固定组与节点保留）。换一个节点固定：回到来源组对新节点按 `f` 即可。

### 4. 切路由预设（首页）

首页「路由」区有四个预设：

| 预设 | 行为 |
| --- | --- |
| GFW 模式 | 仅代理被墙域名，其余直连 |
| 中国列表以外 | 国内直连，其余走代理 |
| 中国列表 | 国内走代理，其余直连 |
| 全局代理 | 全部流量走代理 |

`j/k` 选中后 `Enter` 会先展示将写入的完整 DSL，`y` 确认替换，再按 `A` 重载生效。预设用的代理组可用 `g` 切换。已有自定义规则时显示「自定义规则」，预设只在确认后才覆盖。

### 5. 管理订阅与节点

- **订阅页**（`3`）：`u` 更新订阅、`e` 原地编辑标签与链接（保留 ID，群组挂载不丢）、`c` 编辑定时刷新 cron、`y` 复制订阅链接。
- **手动节点页**（`4`）：`a` 批量导入——每行一条分享链接，整段粘贴即可，坏链接逐条报错不影响其他；`Tab` 后按 `G` 把节点加入某群组。

### 6. 改配置（配置页，数字键 `5`）

左栏三个分区盒（全局配置 / DNS / 路由规则），`Tab` 循环切换：

- `Enter` 切换选中的方案（同样要 `A` 重载）；
- `e` 编辑：全局配置是字段表（含默认值与说明、客户端预校验）；DNS/路由默认调 `$EDITOR` 改 DSL，改完先做后端语法校验、再展示 diff，`y` 才提交。想用应用内编辑器，在 `~/.config/dae-tui/config.toml` 里加 `editor = "builtin"`；
- `v` 在 DSL 原文与结构化概览间切换；
- `E` 导出备份（TOML，只含方案数据，**不含任何凭据**），`w` 落盘 `y` 复制。

## 键位速查

### 全局（任何页面）

| 键位 | 作用 |
| --- | --- |
| `1`–`5` | 首页 · 群组 · 订阅 · 手动节点 · 配置 |
| `j` / `k` | 上下移动 |
| `Tab` / `l` / `h` | 切换 / 进入 / 返回左右两栏 |
| `A` | 重载代理（确认框列出待生效清单） |
| `r` | 全量刷新所有数据 |
| `P` | 设置：账户、主题、语言、自动重载、快捷键、关于（含链路自检） |
| `ctrl+p` | 命令面板：模糊搜索直达跳页/跳组/切方案 |
| `?` | 帮助浮窗（自动定位到当前页的小节） |
| `q` | 退出 |

### 各页精选

| 页面 | 常用键位 |
| --- | --- |
| 首页 | `s` 启动/停止代理 · `Enter` 应用路由预设 · `Tab` 切路由/组焦点 · 组行 `Enter` 跳群组页 · `g` 换预设代理组 · `S`(组行) 切换路由用组 · `x` 解除固定 · `L` 看 daed 日志（本机） |
| 群组 | `space` 标记节点 · `v`/`V` 区间标记/取消 · `U` 清空标记 · `t`/`T` 测速 · `f` 固定节点 · `p` 改组策略 · `c`/`R`/`D` 建/改名/删组 · `s`/`n`/`x` 挂订阅/加节点/移除 |
| 订阅 | `u` 更新 · `e` 编辑 · `c` 定时 cron · `x` 删除 · `y` 复制链接 · `t`/`T` 测速 |
| 手动节点 | `a` 批量导入 · `e` 编辑 · `x` 删除 · `G` 加入群组 · `y` 复制链接 · `t`/`T` 测速 |
| 配置 | `Enter` 切换方案 · `e` 编辑 · `v` DSL↔概览 · `E` 导出备份 · `y` 复制 DSL |

鼠标已启用：滚轮滚动、点击页签切页、点击行选中、双击等同 Enter（配置页与首页预设除外——它们的 Enter 有副作用）。

所有字母数字键位都可以改：`P` → 快捷键，选中动作按 `Enter` 改键、`d` 恢复默认；或直接编辑 `~/.config/dae-tui/keys.toml` 后在 TUI 里按 `r` 重载。

## 命令行非交互模式

适合绑快捷键、写脚本、接监控：

```bash
./dae-tui -probe                          # 只读自检，打印后端全貌

./dae-tui -cmd status                     # 一行式：dae 版本/运行态 + 组 + 选中方案
./dae-tui -cmd groups                     # 只打印组行（格式与 status 共享，可 awk）

./dae-tui -cmd test                       # 触发全部节点测速
./dae-tui -cmd test -g proxy              # 按组名测（逗号分隔多个）
./dae-tui -cmd test -n node-id-1,node-id-2  # 按节点 ID 测

./dae-tui -cmd switch-dns -name default     # 按名切换 DNS 方案
./dae-tui -cmd switch-routing -name gfw     # 按名切换路由方案
```

注意：`switch-*` **只选择不重载**——重载是确认门控的操作，CLI 不会替你按下；输出里会提示「重载后生效」。`test` 只触发测速，结果要在 TUI 的节点列表里查看。

## 配置文件

都在 `~/.config/dae-tui/` 下：

```toml
# config.toml（含凭据，权限 0600）
# endpoint = "http://127.0.0.1:2023/graphql"
# lang = "en"              # 默认中文；改后 -h 帮助文本也跟着切换
# editor = "builtin"       # DNS/路由用应用内编辑器（默认调 $EDITOR）
# theme = "浅色"            # 见下
# auto_reload = true       # dae-tui 自己的改动延迟 2s 自动重载（默认关）
# accent / border / dim / ok / warn / err / gray / sel_bg   # 8 槽调色板（ANSI-256 或 #rrggbb）
```

- **主题**：内置 `默认`、`浅色` 与九个色系主题（北欧/夜航/布丁/玫瑰/青竹/石青/暖橙/水墨/晨光）；自定义主题放 `~/.config/dae-tui/theme/*.toml`，文件名主干即主题名，同样 8 个颜色槽。设置浮窗 `P` 里可以实时预览切换。
- **键位**：`keys.toml`，按「作用域 + 动作」覆盖默认键（加载时会做冲突与遮蔽检测）。设置里改键是更稳妥的入口。

## 常见问题

**连不上 / 登录失败**
确认 daed 正在运行、`-endpoint` 指向 `.../graphql`；远程后端先建好 SSH 隧道。要彻底重置会话：备份或删除 `~/.config/dae-tui/config.toml` 后重新登录。

**首页流量数据不对**
大概率是后端旧 wing 链的统计问题。`P` → 关于 → 链路自检：黄字提示即旧链，修法见 [daed-bare-metal-install.md](daed-bare-metal-install.md)，不需要改 dae-tui。

**改了配置没生效**
方案切换、订阅更新、群组改动都需要重载：顶栏黄字 `⚠ 需重载 (A)` 时按 `A` 确认。嫌繁琐可开「自动重载」。

**测速一直失败**
测速依赖 daed 的 eBPF 核心。`--api-only` 的联调实例测速会返回 `record not found`，属预期；真实运行的 daed 才能测。

**界面错位 / 键位不响应**
终端需支持 UTF-8 与 ANSI 颜色，窗口至少 60×12（过小会显示降级页）。若改过键位，帮助浮窗和外框键位条显示的永远是当前生效键。

**剪贴板复制没反应**
`y` 走 OSC 52，需要终端支持（主流终端与 SSH 均可）；本地无终端的管道环境下会以 toast 提示失败。
